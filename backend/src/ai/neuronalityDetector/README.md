## Unicode-based Neuronality Detector

Данный модуль реализует эвристический подход к определению
вероятности генерации текста нейронной сетью.

### Принцип работы
Детектор анализирует исключительно:
- Unicode-символы
- типографские знаки
- невидимые форматные маркеры
- структурные паттерны текста

### Ограничения
- не использует машинное обучение
- не анализирует семантику
- не зависит от языка
- не требует обучающих данных

Модуль используется исключительно в исследовательских целях
в рамках дипломной работы.
